Resumo do fluxo principal (caminho feliz)

Identificar Cliente → Cliente Identificado
→ Cadastrar Veículo → Veículo Cadastrado
→ Criar Ordem de Serviço → Ordem de Serviço Criada
→ Iniciar Diagnóstico → Diagnóstico Iniciado
→ Registrar Problema Encontrado → Problema Registrado
→ Adicionar Serviço → Serviço Adicionado na OS
→ Adicionar Peça → Peça Adicionada na OS
→ Finalizar Diagnóstico → Diagnóstico Finalizado
→ [Política] Gerar Orçamento → Orçamento Gerado
→ Enviar Orçamento ao Cliente → Orçamento Enviado
→ Aprovar Orçamento → Orçamento Aprovado
→ [Política] Iniciar Execução → Execução Iniciada
→ Debitar Peças do Estoque → Estoque Atualizado
→ Finalizar Execução → Execução Finalizada
→ Entregar Veículo → Veículo Entregue

Fluxo alternativo (recusa do orçamento)
Orçamento Enviado
→ Orçamento Recusado
→ [Política] Cancelar OS
→ Cancelar Execução → Ordem de Serviço Cancelada
